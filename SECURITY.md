# Security

Do not put API keys, credentials, private media, local settings, runtime stores, or unredacted logs in issues, pull requests, screenshots, or source commits. Before sharing diagnostics, inspect them for access tokens, signed URLs, personal paths, and other private information.

Please report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository, if it is enabled. Do not publish exploit details or sensitive reproduction data in a public issue. If private reporting is unavailable, do not disclose the details publicly; use an appropriate private channel already provided by the project maintainers.

Reports should include the affected version or commit, platform, impact, and concise reproduction information, with secrets and personal data removed. No response-time or support guarantee is implied.
